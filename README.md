### ⚡ Sobre Mí & Mis Focos

Tengo una fuerte pasión por simplificar lo complejo y automatizar lo rutinario. Combino mis conocimientos de programación con el análisis de datos para generar soluciones de alto impacto.

- 📊 **Análisis y Dashboards:** Extracción de valor a partir de datos crudos y creación de paneles interactivos para decisiones estratégicas.
- 💻 **Desarrollo de Software:** Programación robusta con bases sólidas en JavaScript (Node.js) y Python.
